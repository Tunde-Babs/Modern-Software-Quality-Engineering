# Part XI – System Design & Architecture

---

## Overview

Understand how software architecture influences quality, scalability, maintainability, and long-term system evolution.

---

## Purpose

Equip Quality Engineers to evaluate architecture from a quality perspective.

---

## Learning Outcomes

Readers will learn to:

- Interpret software architectures
- Evaluate architectural quality attributes
- Understand distributed systems
- Analyse design trade-offs
- Assess system scalability
