# Part VIII – Observability & Reliability Engineering

---

## Overview

Learn how modern engineering teams monitor, measure, troubleshoot, and improve software reliability using observability practices.

---

## Purpose

Develop the ability to engineer highly observable and reliable software systems.

---

## Learning Outcomes

Readers will learn to:

- Understand observability
- Monitor distributed systems
- Analyse logs, metrics and traces
- Define Service Level Objectives (SLOs)
- Improve system reliability
- Support incident response
