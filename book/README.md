# Modern Software Quality Engineering Handbook

## Overview

The MSQE Handbook is organised into twelve parts, progressing from foundational concepts to advanced engineering practices.

Each part is designed as a standalone learning module while contributing to the complete Modern Software Quality Engineering Body of Knowledge (MQE-BOK).

This handbook is intended for:

- Automation Engineers

- Engineering Managers

# Primary Goal

Enable Software QA Engineers to transition into modern Quality Engineers through structured learning, practical laboratories, engineering case studies, and real-world examples.
