# Part VII – Cloud & DevOps for Quality Engineers

---

## Overview

Modern software quality is inseparable from modern software delivery. This part explores how Quality Engineers contribute to cloud-native development, DevOps, Infrastructure as Code, Continuous Integration and Continuous Delivery (CI/CD), containerization, Kubernetes, and deployment strategies.

Readers will learn how quality is engineered throughout the software delivery pipeline rather than validated after deployment.

---

## Purpose

Develop the knowledge and practical skills required to build, test, deploy, and monitor high-quality software in cloud-native environments.

---

## Learning Outcomes

Upon completion of this part, readers will be able to:

- Explain Cloud Computing fundamentals
- Understand DevOps culture and practices
- Build CI/CD pipelines
- Apply Infrastructure as Code principles
- Understand Docker and Kubernetes
- Integrate testing into deployment pipelines
- Engineer quality throughout software delivery
