# Part X – Performance & Security Engineering

---

## Overview

Performance and security are fundamental quality attributes. This part introduces techniques for designing resilient, secure, and high-performing software systems.

---

## Purpose

Develop practical skills for performance testing and secure software engineering.

---

## Learning Outcomes

Readers will learn to:

- Conduct performance testing
- Identify bottlenecks
- Understand secure software principles
- Perform security testing
- Assess software risks
